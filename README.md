# Assessment Test - PT FOMO Inovasi Teknologi

Repository ini berisi kode sumber untuk penyelesaian **Fullstack Engineer Assessment Test**. Proyek dibagi ke dalam dua direktori sesuai dengan dua tugas yang diberikan:

1. **Task 1 (`task-1-api`)**: RESTful API toko online yang dibangun menggunakan Laravel. Dirancang khusus untuk menangani *flash sale* dan mencegah *race condition* (stok minus).
2. **Task 2 (`task-2-cli`)**: Program CLI sederhana menggunakan PHP Native untuk memprediksi posisi item tersembunyi pada sebuah *grid*.
